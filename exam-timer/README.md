Exam-timer is a simple CLI stopwatch, you input a time varible, number of questions and it will pace you.

> ## General summary of contents
> - `exam_timerV1.py` The first version of the exam timer

## How it works
1. Input the total time for an exam
2. Input the total number of questions

THe script will tell you, what question you should be on, and how long you have left/elasped.

## Examples

- Input 40 minutes
- Inputs 10 questions on the paper
The script will calculate it to be 4 minutes a question, showing what question you should be on and time based infomation.
