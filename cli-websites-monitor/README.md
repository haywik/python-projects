Cli-website-monitor is a CLI tool to monitor mutliple sub domains at once, it sends a GET request to the domains /status-b path for data.

> ## General summary of contennts
> - `website-monitorV1.py` is version 1 of the script, for monitoring websites.
> - `archive` Dead or unmaintanied scripts.

## How it works
1. Open up the python program
2. Input your subdomains
3. Run the script

> [!NOTE] 
- - The website must have JSON data at /status-b path
